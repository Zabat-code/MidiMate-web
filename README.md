# MidiMate (Web)

A standalone, single-file web piano application. Open `index.html` in any modern
browser — no build step, no installation.

## Features

- On-screen piano keyboard (mouse, computer keyboard, or physical MIDI device)
- MIDI file loading and playback with a falling-notes roll and a musical staff
- Multiple synth/instrument presets
- Visual themes, key styles, and touch effects
- Customizable backgrounds (image, GIF, or video layers)
- Note-naming systems: English (C D E), Latin (Do Re Mi), German (C D E H)
- Screen modes: Free play, View, and Practice
- Video export of the performance

## Usage

Just open `index.html`. For MIDI device support, grant browser access when
prompted.

## Status

**Work in progress.** The app is functional but still under active development.
Features and UI may change.
